# QuantBench

QuantBench is a greenfield Windows desktop workstation for researching, backtesting, validating, and safely deploying futures strategies through NinjaTrader 8. Version 1 focuses on CME NQ, MNQ, ES, and MES futures.

The platform is designed around reproducibility, realistic execution modeling, prop-firm account economics, deterministic risk controls, single-account trade routing, and complete operational auditability. AI may assist with strategy authoring and incident analysis, but it never controls orders, risk, rules, or deployments.

Development proceeds through strict sequential safety gates. Read [PLAN.md](PLAN.md) before starting any project work; it is the controlling specification for scope, architecture, implementation order, and acceptance criteria.
