# INC-YYYY-NNN: Incident title

| Field | Value |
|---|---|
| Severity | P0/P1/P2/P3 |
| Detected at | UTC timestamp |
| Event began | UTC timestamp or unknown |
| Owner | Accountable role and name |
| Status | Open/Contained/Resolved/Closed |

Record affected assets/accounts, chronological evidence, containment, reconciliation, root cause, corrective actions, approvals, and closure criteria. Unknowns remain explicit and fail closed.
