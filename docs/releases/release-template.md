# Release `VERSION`

| Field | Value |
|---|---|
| Commit | Full commit SHA |
| Tag | Signed immutable tag |
| Owner | Release owner |
| Approval | Review link and approvers |
| Phase authority | Highest accepted phase |

## Included requirements and evidence

List stable requirement IDs, test reports, SBOM hashes, and artifact signatures.

## Known limitations and deployment authority

State limitations and the maximum permitted operating mode. Absence of a statement means no operational trading authority.

## Rollback

Identify the prior accepted release and exact rollback/containment procedure.
