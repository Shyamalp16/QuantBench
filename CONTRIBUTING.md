# Contributing to QuantBench

Read `PLAN.md` and the latest accepted phase record before changing the repository. Work on a `codex/` or contributor branch, keep changes within the current authorized phase, reference stable requirement IDs, and use `pwsh ./tools/verify.ps1` once the phase work is complete.

Never commit credentials, account identifiers, third-party full-page evidence snapshots, unsigned release claims, or code belonging to a later phase. Architecture, safety, phase, threshold, firm, instrument, and live-behavior changes require the approved change-control process.
